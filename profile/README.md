# Tony Chase Archive

We collect, preserve, and share Tony Chase's videos, transcripts, and related material so fans and researchers can find and watch them.

The archive lives at [tonychasearchive.com](https://tonychasearchive.com). You can browse videos, search titles and transcripts for words or exact phrases, save favorites, make video lists, and leave ratings and comments. There's also a 24/7 Live channel and separate archive and Live chat rooms. Videos with completed caption tracks have synchronized English captions.

## Behind the archive

This organization holds the website and the tools we use to keep the archive running:

- Video download and upload scripts that save Tony's YouTube videos to object storage.
- Transcription tools built around Whisper and WhisperX, plus scripts that upload transcripts and import them into the search database.
- Recovery tools that check the video archive against the transcript database and process missing entries.
- The website's player, search, lists, chat, and Live channel, with a shared light/dark interface and a separate WebSocket service for chat updates.
- Admin monitoring for account activity, service health, requests, errors, incidents, and audit history, built into the existing panel.
- A C-based bulletin board system, a custom video player project, and earlier website code.

The application and tool repositories require repository access. Their READMEs contain setup instructions and project details; this organization profile is public.

## Help out

Developers, archivists, and fans are welcome. Join us on Discord to talk about the archive or ask where help is needed. Contributors with repository access can open issues and send pull requests there.

We think archiving takes care and patience, and that even the small bits are worth saving. Cannabis helps fuel the team, too.
